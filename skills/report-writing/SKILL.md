# 报告写作规范

## 结构（按顺序）

1. **标题**：一句话说清主题
2. **结论先行**：先把核心结论/要点摆前面，再展开
3. **分点展开**：每个要点一个小标题 + 简短说明
4. **数据/事实支撑**：能引用就引用，不空谈
5. **建议/下一步**（如适用）

## 语言

- 简洁，一句一个意思，别绕
- 少用空话套话（"综上所述""众所周知"这类删掉）
- 数字用阿拉伯数字，单位统一
- 面向谁写就说什么话（给小白就少用术语）

## 格式

- 用 markdown 标题分层（# ## ###）
- 列表清晰、层级不超过 3 层
- 重要结论加粗
- 有数据尽量做成表格
