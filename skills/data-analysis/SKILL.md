# 数据分析规范

## 步骤

1. **先看数据长什么样**：有哪些列、行数、类型、有没有缺失或异常值
2. **描述性统计**：平均、最大最小、分布、占比
3. **找规律**：趋势、对比、异常点、相关性
4. **给结论**：每个结论都配上能追溯到数据里的依据

## 注意

- 先看数据再下结论，绝不凭空猜
- 数字要核对一遍，别算错（算完可以用工具验证）
- 结论和依据分开写，让用户能自己判断
- 发现数据本身有问题（缺失、明显错值）要先说
