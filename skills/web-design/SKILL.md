# 现代网页设计规范

你生成任何网页时，严格遵循本规范。目标是"专业、克制、好看"，而不是"默认模板感"。

## 一、设计原则

1. 克制：一个页面主色不超过 2 个，加 1 个点缀色；别堆渐变色块和花哨阴影。
2. 层级分明：靠字号和字重区分标题/正文，不靠乱配色。
3. 留白充足：内容之间、卡片之间留足呼吸空间，宁松勿挤。
4. 统一栅格：所有间距取 4 的倍数（4/8/12/16/24/32/48）。
5. 一致性：同类型元素（按钮、卡片、输入框）全站用同一套圆角和阴影。

## 二、设计 Token（直接抄进 :root）

```css
:root {
  /* 配色（浅色主题，克制） */
  --bg: #ffffff;
  --bg-subtle: #f7f7f8;        /* 卡片/分区底 */
  --border: #e6e6e8;
  --text: #1a1a1c;             /* 主文字 */
  --text-muted: #6b6b72;       /* 次要文字 */
  --accent: #4f46e5;           /* 主色（按钮/链接） */
  --accent-soft: #eef0ff;      /* 主色的浅底 */
  --danger: #d64545;

  /* 字体层级 */
  --font: -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif;
  --fs-h1: 34px; --fs-h2: 24px; --fs-h3: 18px;
  --fs-body: 15px; --fs-small: 13px;

  /* 间距 */
  --sp-1: 4px; --sp-2: 8px; --sp-3: 12px; --sp-4: 16px;
  --sp-5: 24px; --sp-6: 32px; --sp-7: 48px;

  /* 圆角 & 阴影（统一） */
  --radius: 10px; --radius-lg: 16px;
  --shadow: 0 1px 3px rgba(0,0,0,.06), 0 1px 2px rgba(0,0,0,.04);
}
```

## 三、组件规范

- **按钮**：主按钮 = 主色底白字、圆角 8px、内边距 10px 20px；次按钮 = 白底 1px 边框。悬停主色加深 8%，别用渐变。
- **卡片**：白底、1px `--border` 边框、圆角 `--radius-lg`、内边距 `--sp-5`、`--shadow` 阴影；卡片间用 `--sp-5` 间隔。
- **导航栏**：白底、底 1px 边框、左 logo 右链接，高 56px。
- **Hero 区**：标题 `--fs-h1` + 一句副标题（muted）+ 一个主 CTA 按钮，垂直居中，`--sp-7` 上下留白。
- **输入框**：白底、1px 边框、圆角 8px、聚焦时边框变主色（1px→1.5px 过渡）。
- **字体**：正文 `--fs-body`/1.7 行高；标题用 600 字重；正文 400。

## 四、响应式

- 用 CSS Grid/Flexbox；移动端（<768px）单列堆叠，Hero 标题降到 26px。
- 卡片栅格：桌面 3 列 → 平板 2 列 → 手机 1 列（`grid-template-columns: repeat(auto-fit, minmax(240px, 1fr))`）。
- 图片 `max-width:100%`，别写死绝对定位布局。

## 五、检查清单（交付前逐条过）

- [ ] 颜色只用 Token，无 `#007BFF`/`#F8F9FA` 之类随机值
- [ ] 间距全是 4 的倍数
- [ ] 标题/正文层级清晰（h1>h2>h3>body）
- [ ] 同类型组件圆角、阴影一致
- [ ] 无渐变堆砌、无多余阴影
- [ ] 移动端可读、不横向溢出
- [ ] 中文字体用 PingFang/微软雅黑，字号不小于 13px
