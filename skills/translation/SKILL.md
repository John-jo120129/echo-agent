# 翻译规范

1. **准确第一**：忠实原文，不增、不减、不曲解
2. **自然流畅**：符合目标语言表达习惯，不生硬直译
3. **术语一致**：专业术语用通用译法，前后统一
4. **保留不译**：数字、专有名词、代码、文件名、品牌名保留原样
5. **语境适配**：正式/口语/技术文档语气要贴合场景

## 输出

- 直接给译文，必要时在译文后加简短括号说明
- 术语拿不准时标注，不硬编
