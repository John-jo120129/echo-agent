# Echo 回声 · 使用手册

> 面向使用者：每个按钮干什么、怎么用最顺手、遇到问题怎么办。

---

## 一、网页版界面

打开 http://127.0.0.1:8899 后，你看到的是：

```
┌──────────────────────────────────────────────────────────┐
│ 回声 Echo          [会话▾] [＋新对话] [🗑] [⏰] [🎧] [🌙] [✦]│
├──────────────────────────────────────────────────────────┤
│                                                          │
│  你说的话 ◀───────────────────────────                   │
│                                                          │
│                    ───────────▶ 它的回复                  │
│                                                          │
│  ▸ 查看思考过程（5 步）  ← 点开看它怎么想的               │
│                                                          │
├──────────────────────────────────────────────────────────┤
│  [说目标，或点🎤直接说话                    ] [📷] [🎤] [发送]│
└──────────────────────────────────────────────────────────┘
```

### 顶部按钮

| 按钮 | 作用 |
|------|------|
| **会话 ▾** | 切换历史对话（标题是你说的第一句话） |
| **＋ 新对话** | 开一个新会话，旧的不丢 |
| **🗑** | 删除当前会话（会问你确认） |
| **⏰** | 定时任务：每天到点自动干活 |
| **🎧 语音模式** | 回复自动朗读，你一说话就打断它 |
| **🌙 / ☀️** | 深色 / 浅色模式（会记住你的选择） |
| **✦ 记忆星球** | 3D 可视化看它记住了什么 |

### 底部输入

| 元素 | 作用 |
|------|------|
| 文本框 | 打字说目标，Enter 发送，Shift+Enter 换行 |
| **📷** | 发图片给它看（需要 `ollama pull qwen2.5vl:7b`） |
| **🎤** | 说一句话，自动转文字（语音模式下说完自动发） |
| **发送** | 或按 Enter |

## 二、语音怎么用

### 单次说话
点 **🎤** → 说话 → 说完再点一次（或静音 0.9 秒自动停）→ 它识别后填进输入框。

### 语音模式（推荐）
点 **🎧 语音模式** → 按钮变蓝：

1. 你说话 → 录音 → 静音 0.9 秒自动停 → **自动发送**
2. 它回复 → 自动朗读
3. **你随时插话 → 它立刻闭嘴**（VAD 检测到人声）
4. 打断后自动开始录音，继续对话

这就是"像人一样对话"。

> 需要浏览器允许麦克风。Chrome/Edge 都行。

## 三、定时任务

点 **⏰** → 填时间和任务 → 添加：

```
时间：08:00
任务：汇报今天的天气
```

之后每天 8 点它会自动干这件事，结果写进当前会话。

> 注意：网页版（`python webui.py` 或 exe）或命令行版（`启动.bat`）开着才会执行。

## 四、记忆

| 说法 | 它做什么 |
|------|---------|
| "记住我喜欢喝可乐" | 记进短期记忆 |
| "记成长期记忆：下周三考试" | 记进长期记忆 |
| "记住我生日是 3 月 5 号" | 记进用户档案 |
| "你还记得我喜欢什么吗" | 检索记忆回答你 |
| "加个待办：明天交作业" | 加待办 |
| "写篇日记：今天有点累" | 写日记 |

**自动记忆**（不用你说）：
- 你提到"我叫X / 我喜欢X / 我在做X" → 自动提取成事实
- 任务失败 → 自动总结教训，下次避开

想清空：命令行 `/forgetall`（慎用）。

## 五、技能

技能 = 预先写好的做事规范（数据分析、写报告、翻译、网页设计）。

| 说法 | 它做什么 |
|------|---------|
| "有哪些技能" | 列出全部 |
| "加载数据分析技能" | 加载规范再干活 |

**自动沉淀**：一个任务用了 3 步以上工具并成功完成，它会自己总结成新技能，下次遇到类似的直接参考。

技能文件在 `skills/` 目录，可以手动编辑。

## 六、命令行版（可选）

`python echo.py` 或双击 `启动.bat`。

### 常用指令

| 指令 | 作用 |
|------|------|
| `/help` | 全部指令 |
| `/model qwen2.5:14b` | 换大脑（越大越聪明越慢） |
| `/multi` | 开关「规划→执行→反思」三阶段 |
| `/tasks` | 看最近任务记录 |
| `/log` | 看操作日志 |
| `/auto` | 危险命令自动确认（不建议开） |
| `/stealth` | 操控模式：可视化/隐藏 |
| `/listen` | 语音输入 |
| `/speak 内容` | 朗读 |
| `/speak_auto` | 回复自动朗读 |
| `/schedule 08:00 任务` | 定时任务 |
| `/organize` | 把记忆归纳成画像 |
| `/star` | 打开记忆星球 |
| `/reindex` | 重建知识库索引 |
| `/exit` | 退出 |

### 危险操作确认

执行删除/格式化/关机这类命令时，它会停下来问你：

```
⚠ 危险命令：rm -rf build
要执行吗？(y/N)
```

网页版对应的是**弹窗**，你点"允许/拒绝"。

## 七、知识库（RAG）

1. 把你的 `.md` 笔记丢进 `kb/` 文件夹
2. 命令行跑 `/reindex`
3. 之后问相关内容，它会先查知识库再回答

支持中文检索（用 `mxbai-embed-large` 向量模型）。

## 八、常见问题

### 提示"连不上模型"
```bash
ollama serve
```
或重启 Ollama。

### 提示"python 不是内部或外部命令"
Python 没装或没勾 `Add Python to PATH`。重装时勾上。

### 网页版打不开
- 确认程序在跑（命令行窗口没关）
- 端口被占：`netstat -ano | findstr 8899`

### 语音不工作
- 浏览器地址栏左侧允许麦克风
- 必须用 `http://127.0.0.1:8899` 或 `localhost`（HTTPS 或本地才允许麦克风）

### 图片看不了
需要视觉模型：
```bash
ollama pull qwen2.5vl:7b
```

### 回复很慢
- 7b 比 14b 快很多：`/model qwen2.5:7b`
- 关掉 `/multi`（少两次模型调用）

### 它老是说"我来帮你"但不动手
说明模型太小/上下文太乱。试试：
- 换 14b：`/model qwen2.5:14b`
- 说具体点："打开记事本"比"帮我处理下文本"好
- 跑 `python tests.py` 看它工具调用能力是否正常

## 九、进阶

### 换模型（用云端 API）
改 `config.json`：
```json
{
  "api_base": "https://api.deepseek.com/v1",
  "api_key": "你的key",
  "model": "deepseek-chat"
}
```
任何 OpenAI 兼容 API 都行（DeepSeek、通义、Kimi、OpenAI…）。

### 接到 Claude Desktop / Cursor（MCP）
```bash
python mcp_server.py
```
然后配置：
```json
{
  "mcpServers": {
    "echo": {
      "command": "python",
      "args": ["D:/echo-agent/mcp_server.py"]
    }
  }
}
```

### 跑测试
```bash
python tests.py              # 34 条工具调用测试
python tests.py qwen2.5:7b   # 指定模型测
```
通过率 100% 说明工具调用正常。
