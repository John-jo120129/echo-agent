# 示例知识：什么是 AI Agent

AI Agent（智能体）= 大模型大脑 + 工具双手 + 记忆存储。

与普通聊天机器人的核心区别：聊天机器人只能"你问我答"；Agent 拿到目标后会自主规划、调用工具、观察结果、循环推进，直到完成目标才停下汇报。

Agent 的基本工作循环：接收目标 → 思考下一步 → 调用工具 → 观察结果 → 决定继续或汇报。这个循环由代码驱动，大模型负责每一步的决策。

# 示例知识：什么是 RAG

RAG（Retrieval-Augmented Generation，检索增强生成）是给 AI "灌知识"的主流做法：把知识文档切块并向量化存入索引；提问时把问题也向量化，检索出最相关的几段，塞给大模型当参考资料再回答。

RAG 相比微调的优势：知识可随时增删（改文件重建索引即可）、不会让模型变笨、不需要训练算力。适合个人知识库问答场景。

# 示例知识：本地部署大模型

Ollama 是最流行的本地大模型运行器。装好后 `ollama pull 模型名` 下载模型，`ollama serve` 启动服务。它提供 OpenAI 兼容接口（/v1/chat/completions），所以任何按 OpenAI 格式写的程序都能无缝切换本地/云端模型。

模型大小的经验：7b 约需 8GB 显存全速运行；14b 在 8GB 显存上会自动 CPU 分担、速度中等；参数越大越聪明也越慢。
